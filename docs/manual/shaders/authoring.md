# Shader Authoring
> [!WIP]

> [!TIP]
> Whilst shaders are typically created from a `.slang` asset, they can also be made in-code from a source string using the <xref:Beryl.Rendering.Resources.Shader> constructor.
> ```csharp
> new Shader(<ShaderSource>);
> ```

Writing a shader begins with creating a `.slang` file.
