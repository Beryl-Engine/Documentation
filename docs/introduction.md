# Introduction
> [!WARNING]
> Orama is in constant iteration. This documentation may not always perfectly reflect the most up-to-date engine version.

Welcome to the documentation/wiki for the **[Orama Game Engine](https://github.com/Orama-Engine/Orama)**! Orama is a cross-platform, MIT licensed, 3D focused game engine built around modern C#. It's designed to give creators an engine that they'll enjoy using, no messy abstractions, no interop artifacts, and no licensing concerns.

## About The Documentation
This documentation is open-source and contributor ran. You can find the source code at [Orama-Engine/Documentation](https://github.com/Orama-Engine/Documentation) or click the `Edit This Page` button in the page footer to instantly get sent to the associated GitHub file.
