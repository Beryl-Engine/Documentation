# Introduction
> [!WARNING]
> Beryl is in constant iteration. This documentation may not always perfectly reflect the most up-to-date engine version.

Welcome to the documentation/wiki for the **[Beryl Game Engine](https://github.com/Beryl-Engine/Beryl)**! Beryl is a cross-platform, MIT licensed, 3D-Focused game engine built around modern C#. It's designed to give fans of C# an engine that they'll enjoy using, no messy abstractions, no interop artifacts, and no licensing concerns.

## About The Documentation
This documentation is open-source and contributor ran. You can find the source code at [Beryl-Engine/Documentation](https://github.com/Beryl-Engine/Documentation) or click the `Edit This Page` button in the page footer to instantly get sent to the associated GitHub file.
